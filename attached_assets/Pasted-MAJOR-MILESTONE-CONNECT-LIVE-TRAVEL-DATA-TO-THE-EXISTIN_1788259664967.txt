============================================================
PRIMARY GOAL
============================================================

Connect trustworthy external travel data to the EXISTING planning system.

Roamwise should evolve from:

good planning intelligence + estimates

into:

good planning intelligence + real-world data + clearly labeled estimates where live data is unavailable.

The principle is:

AI handles judgment and explanation.

Application code handles:
- arithmetic
- dates
- validation
- provider calls
- normalization
- caching
- source tracking

External providers supply facts.

The Travel Decision Engine decides which facts create the most Experience Value for the traveler.

============================================================
3. LIVE FLIGHT DATA MUST NOT BECOME "CHEAPEST FLIGHT WINS"
============================================================

Roamwise is not a flight-search engine.

The Travel Decision Engine should evaluate flight options using multiple factors.

Possible decision dimensions:

- price
- total duration
- number of stops
- departure timing
- arrival timing
- overnight travel
- connection burden
- impact on usable vacation time
- route convenience

Example:

Flight A
$470
2 stops
18 hours

Flight B
$545
nonstop
9 hours

Roamwise should NOT automatically recommend Flight A simply because it is cheaper.

It should be capable of reasoning:

"The nonstop option costs approximately $75 more but preserves almost a full day of usable travel time and reduces connection fatigue."

This is exactly the type of Experience Value decision Roamwise should make.

Do the calculations deterministically where possible.

Use AI primarily to explain the tradeoff.

============================================================
4. FLIGHT → ITINERARY INTEGRATION
============================================================

Do not merely show flights in a disconnected panel.

Flight information should influence planning when appropriate.

For example:

If the selected flight arrives at 8:30 PM:

Day 1 should NOT contain a full sightseeing schedule.

If the return flight departs at 7:00 AM:

the final day should reflect the early departure.

If a significantly better airport improves routing:

Roamwise may explain the alternative.

However:

Do not silently change the user's airport/city without explanation.
